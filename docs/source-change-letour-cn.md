# 来源调整：始祖鸟官网移除、朗途中文站

- 仅移除始祖鸟官网及其山地课堂资源采集，不再检查该官网是否更新或发送相关故障通知。
- 最酷里的“始祖鸟、ARC'TERYX、ARCTERYX”检索、当届品牌活动筛选和跨来源去重保留。
- 朗途由英文展示站替换为中文官方站 `http://www.letoursports.com/`。从首页读取赛事／户外活动分类，支持两种活动列表、分页及直接跳转到单个活动的分类；合并活动 ID 后再核验详情。
- 当届中文标题、正文、报名按钮及公开场次 JSON5 用于确认地点、日期、组别、费用及报名状态。不会执行网页脚本；导航、推荐区不供品牌和地点依据。已截止、已结束、活动进行中的项目不推送。
- 排除赛后邮寄、押金／展位、勋章、志愿者、媒体等服务项目，避免当成新赛事。原有稳定身份和去重状态继续保留。
- 中文站 HTTPS 证书当前与域名不匹配，公开 HTTP 入口可读取。采集仅匿名读取公开页面，不关闭证书验证，不传凭据或提交报名。
- 本地真实读取：34 个朗途分类／分页／详情检查成功，当前没有符合长三角地域、运动范围及开放报名条件的新项目。最酷是品牌活动的补充来源。
- 本地验证：63 项 Python 测试及 11 项 Worker 测试通过。
