## 去重和验证

- 同一最酷报名 ID 从首页、搜索及带跟踪参数链接出现时合并，只读取一次品牌详情。
- 跨官网、朗途、最酷的同届活动，按报名入口、稳定身份、日期及归一化名称去重，保留入口别名；不会合并不同年份或不同日期的独立品牌场次。
- 同一活动同时满足品牌与 A 类等分类时仅生成一条新增通知，优先保留赛事系列／A 类分类；品牌依据不会替代 A 类认证依据。
- 非跟踪的 URL 活动 ID 查询参数保留，普通通用报名门户不能把两个不同活动合并。
- 资料不足、未开放及未核验的新候选不会提前消耗首次通知机会。
- 59 项 Python 测试、11 项 Worker 测试通过，[GitHub CI](https://github.com/biblioth/race-monitor/actions/runs/39923807720)通过。
- 日常依然每天北京时间 09:00 检查，09:30 补偿未完成批次。`refresh=true` 仅供手动复查，继续沿用持久化去重。
